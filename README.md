# Homebrew tap for ClawSec

```bash
brew install lf3551/clawsec/clawsec
```

Builds [ClawSec](https://github.com/LF3551/ClawSec) from source against
Homebrew's `openssl@3` and `argon2`, and installs the man page and
bash/zsh/fish completions.

The formula is updated automatically by ClawSec's release workflow.
